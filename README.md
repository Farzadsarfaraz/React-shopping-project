🛒 Online Shop – Final School Project (Work In Progress)
This is a full-stack Online Shop application built with React.js, Node.js + Express, MongoDB, and Ant Design, currently under development as my final school project.

The project aims to deliver a complete e-commerce experience including product browsing, user authentication, cart management, and order placement. While many core features are implemented, some areas are still being improved and expanded.

🚀 Current Status
Frontend built with React.js and Ant Design for UI.

Backend API created with Node.js, Express, and MongoDB.

User registration and login with JWT authentication implemented.

Product listing and detailed views functional.

Shopping cart features partially complete.

Order placement in progress.

Responsive design mostly done.

🛠️ Technologies Used
React.js + Ant Design (frontend)

Node.js + Express (backend)

MongoDB + Mongoose (database)

JWT for auth

Axios for API calls
